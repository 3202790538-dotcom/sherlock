# Sherlock 图形界面

在 Finder 双击项目根目录的 `启动Sherlock.command`，浏览器会自动打开本地界面。运行期间保留终端窗口；退出时在终端按 Control+C。

输入一个用户名，选择「全球 + 中国网站」或「仅中国／中文网站」，点击「开始探索」。支持实时进度、发现账号/全部结果/连接异常筛选、停止搜索、打开账号页面和导出所有已检测结果至 Excel。停止后保留已有结果，重新搜索会清空上一轮。结果仍采用纯黑底紧凑列表，可结合状态分类和「中国／中文网站」地区筛选查看。

国内平台按账号 ID 或个人主页标识检测，昵称不一定等于用户名。网站登录限制、验证码或连接异常不等于账号不存在；检测结果中可悬停查看详细说明。更多国内平台通过「手动搜索」入口打开站内搜索，需要在目标网站自行确认，且不会计入发现账号或导出为已发现结果。

界面使用本机 Python 3.12 环境 `.venv312`，服务只监听 127.0.0.1，不需要前端安装依赖。搜索使用仓库附带的平台列表并读取上游排除列表，用户名会发送至所检测的网站。结果可能误判，同名不代表同一人。

手动启动：

```sh
.venv312/bin/python -m gui.app
```
